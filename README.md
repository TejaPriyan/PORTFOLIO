## ✨ Features

- 🌌 **Cinematic 3D WebGL World** — Custom Three.js scene rendered with `@react-three/fiber` and `@react-three/drei` reacting to scroll position and cursor motion.
- 🤖 **Priya Digital AI Assistant** — Built-in interactive portfolio guide with quick actions and knowledge about my projects, skills, and background.
- 🎯 **Project Showcases** — Interactive tilt cards with direct links to live deployments and GitHub source code.
- 📊 **Animated Skill Arsenal** — Animated skill meters categorized across LLMs, Computer Vision, Languages, Frontend, and Backend.
- 👁️ **AI Vision Matrix** — Hologram-styled insights highlighting the future of multimodal AI and edge perception.
- 📱 **Responsive & Accessible** — Gracefully optimized across desktop, tablet, and mobile screens.

## 📂 Repository Files & Architecture

```
PORTFOLIO/
├── app/
│   ├── layout.js              # Root layout, SEO/GEO/AEO metadata, JSON-LD, fonts
│   ├── page.js                # Main scroll container coordinating 3D scenes & overlay sections
│   ├── globals.css            # Tailwind custom directives, glassmorphism tokens, and keyframe animations
│   └── api/
│       ├── contact/route.js   # API endpoint handling contact form submissions
│       └── priya/route.js     # Knowledge API supporting the Priya digital guide
├── components/
│   ├── Scene3D.js             # Three.js 3D canvas, lighting, camera choreography, and particle systems
│   ├── HeroOverlay.js         # Opening hero title, typing roles, status badge, and call-to-actions
│   ├── AboutSection.js        # Professional background, education timeline, and technical highlights
│   ├── ProjectsSection.js     # Featured projects grid with 3D tilt hover cards and live launch links
│   ├── SkillsSection.js       # Categorized skill meters covering AI, LLMs, Computer Vision, and Web
│   ├── AIVisionSection.js     # Philosophical vision points and insights on artificial intelligence
│   ├── ContactSection.js      # Contact form, direct email, location, and social media links
│   ├── NavigationBar.js       # Glassmorphic top navigation bar with active section indicator
│   ├── PriyaAssistant.js      # Floating digital portfolio guide chatbot
│   ├── CinematicOverlay.js    # Cinematic viewport letterboxing and ambiance gradients
│   ├── SoundManager.js        # Ambient audio effects and user toggle controls
│   └── LoadingScreen.js       # Preloader animation while Three.js assets initialize
├── public/
│   ├── BingSiteAuth.xml       # Bing Webmaster Tools site verification
│   ├── google87bb3bc53ec346d2.html # Google Search Console site verification
│   ├── robots.txt             # Search crawler directives and sitemap declaration
│   ├── sitemap.xml            # XML sitemap for search engine indexing
│   └── resume.pdf             # Resume PDF
├── next.config.js             # Next.js configuration
├── tailwind.config.js         # Tailwind theme extensions, colors, and animations
└── package.json               # Dependencies and build scripts
```
